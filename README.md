# LrcRed Lyrics (Lyrico 专用逐字歌词插件)

这是一个专门给 [Lyrico](https://github.com/Replica0110/Lyrico) 制作的逐字歌词插件。

简单来说：让你在手机上用 Lyrico 整理本地音乐时，能轻松拿到高品质的TTML逐字歌词，顺带支持转换为带毫秒级词轴的增强型逐字歌词（ELRC），在各种支持流光动效的现代播放器里直接起飞。

---

## 它是怎么来的？与相关项目的关系

- **母项目**：[Music-Tag-Lyrics](https://github.com/sxsxhhi/music-tag-lyrics)
  本插件并不是凭空捏出来的，它的核心检索与仲裁算法直接提取自桌面端音频元数据治理工具 `Music-Tag-Lyrics`。把其中第一优先级的 Apple Music / TTML 官方逐字匹配逻辑单抽出来，为 Lyrico 手机端的轻量环境重构成了即插即用的单文件 JavaScript 插件。
- **宿主项目**：[Lyrico APP](https://github.com/Replica0110/Lyrico)
  Lyrico 是一款专为 Android 打造的本地音频标签与歌词编辑神器。
  - **插件只做一件事**：根据本地歌曲的标签在远端高精度匹配，把原汁原味的官方级逐字 TTML 歌词抓回来递给宿主；
  - **其余全归宿主**：把 TTML 转成增强型逐字歌词（ELRC）、普通 LRC 或双语歌词，以及写入音频 ID3 标签或保存为本地外挂文件，全部由 Lyrico 宿主原生处理。

---

## 真正的双引擎架构

插件内置两条互补的检索链路，全自动调度：

1. **主引擎（Apple Music TTML）**：
   - 先通过 iTunes Search 智能探测匹配店面（按语种自动优先搜 `hk`、`tw`、`us`、`jp`），精确定位曲目的 Apple Music ID；
   - 随后直连 AMLL TTML DB 社区镜像源拉取官方逐字 TTML 歌词，时间轴精确到音节，字级丝滑对齐。
2. **备用引擎（lrc.red）**：
   - 拥有海量全球同步词库，支持通过音频内嵌的 12 位 ISRC 编码直连命中，或走曲名/艺人结构化检索；
   - 一旦主引擎查无此歌或网络受阻，毫秒级无缝切入备用源兜底。

## 核心亮点：为什么用它？

- **优先拿官方级逐字 TTML**：超级无敌牛逼的逐字歌词，质量暴打163、QQ、酷狗等源获取到的逐字歌词，绝不糊弄事
- **智能版本识别，坚决不张冠李戴**：搜歌词最恶心的就是原曲配上现场版，时间轴彻底崩塌。插件内置严密的反向拦截逻辑，遇到 Live、Remix、现场版、伴奏等版本自动拦截；而像 Remastered（重制版）、Deluxe（豪华版）这种时间轴完全兼容的版本则聪明放行。
- **12 小时本地查询缓存**：反复试听、反复切歌或批量整理同一张专辑时，完全由本地缓存秒级返回，彻底告别接口频繁请求导致的 429 限流问题。
- **零门槛即插即用**：哪怕完全不配置联系邮箱，主引擎也全功能正常运作；配置邮箱仅用于解锁 lrc.red 备用源，但强烈建议填写邮箱，因为主引擎收录的歌词较少

## 保姆级安装与使用指引

### 第一步：获取插件
去本仓库的 [Releases 页面](https://github.com/sxsxhhi/LrcRed-Lyrics-Lyrico/releases) 下载最新版的插件包（认准文件名形如 `LrcRed-Lyrics-x.x.x-Lyrico-Plugin.zip`）。
> **切记**：下载完**不要解压**，直接留着 `.zip` 文件。

### 第二步：导入到 Lyrico
1. 打开手机上的 **Lyrico**；
2. 依次点击：**设置** → **搜索设置** → **插件管理**；
3. 点击右上角 **「+」** 号，选 **本地导入**；
4. 找到并选择刚才下载的 `.zip` 压缩包，秒装完成。

### 第三步：设置歌词输出格式（强烈推荐 ELRC）
1. 在 Lyrico 里进入 **设置** → **歌词** → **歌词模式**；
2. 建议勾选 **增强型逐字歌词 (ELRC)**；
   - 这样 Lyrico 在保存歌词时，就会把插件抓到的 TTML 原生逐字数据转成带有 `<mm:ss.xxx>` 毫秒时间轴的 ELRC，在各类现代播放器中即可完美享受逐字流光动效。

### 第四步：给歌曲刮削歌词
1. 在 Lyrico 歌曲列表或单曲编辑界面，点击 **「搜索歌词」**；
2. 搜索源勾选 **LrcRed Lyrics**；
3. 出来候选后点击可直接预览，确认歌词和时间轴完全对齐后，点击 **应用**；
4. 最后点击右上角保存（**✓**），搞定！逐字歌词已稳稳写进音频标签或保存为同名外挂歌词。

## 常见问题

- **Q: 插件设置里的联系邮箱到底填不填？**
  - **不填完全不影响主引擎**：Apple Music 逐字源检索不需要任何凭证，留空即可开箱即用。但歌词资源较少
  - **填了有啥用？**：第三方开源词库 lrc.red 的 API 条款规范要求客户端携带合规的联系邮箱标识。如果你希望在主引擎缺词时自动切入 lrc.red 备用库兜底，建议填一个真实邮箱；未填写时插件会自动跳过备用库，保证不会因为网络报错弹窗打扰你。
- **Q: 为什么有些歌曲搜不出来？**
  - 因为AM高质量逐字歌词本来资源就不是很多，中文歌曲更少，大多都是欧美热门歌曲。但歌词质量精度都是杠杠的，绝不糊弄。
