# LrcRed Lyrics (Lyrico 专用逐字歌词插件)

这是一个专为 [Lyrico](https://github.com/lyrico-app/lyrico) 本地音乐播放器定制的双引擎逐字歌词检索插件。

---

## 项目渊源与架构定位

- **母项目**：[Music-Tag-Lyrics](https://github.com/sxsxhhi/music-tag-lyrics)
  本插件的核心检索与逐字解析逻辑，提取自桌面端音乐元数据处理工具 `Music-Tag-Lyrics` 中的高优先级逐字匹配算法。针对移动端播放器的轻量运行环境，进行了单文件 JavaScript 架构的重构与性能优化。
- **宿主项目**：[Lyrico APP](https://github.com/lyrico-app/lyrico)
  Lyrico 是一款出色的 Android 本地音乐播放器。本插件作为 Lyrico 的扩展插件运行，职责边界非常清晰：插件只负责精准检索并输出结构化逐字数据（TTML 格式）；流光动效渲染、排版呈现与歌词同步由播放器原生高效驱动。

---

## 核心特性

1. **双引擎无缝调度**
   - **主引擎**：优先检索高品质原生逐字歌词源，字级精准对齐；
   - **备用源**：当主引擎无可用数据时，自动平滑切换至开源备用词库进行补充。
2. **智能版本识别**
   - 内置音频版本互斥与兼容规则，有效避免将原曲错配至现场版（Live）或混音版（Remix）；同时对重制版（Remastered）等时间轴兼容版本予以放行。
3. **本地查询缓存**
   - 内置 12 小时本地查询缓存机制，针对切歌与重播场景实现秒级响应，大幅减轻网络请求压力。
4. **开箱即用，无需繁琐配置**
   - 默认无需配置任何密钥或邮箱即可直接使用主引擎；如需启用第三方开源备用库，可在插件设置中选填联系邮箱。

## 安装与使用步骤

### 第一步：下载插件包
前往本仓库的 [Releases 页面](https://github.com/sxsxhhi/LrcRed-Lyrics-Lyrico/releases) 下载最新版本的插件包（文件名为 `LrcRed-Lyrics-x.x.x-Lyrico-Plugin.zip`）。
> **提示**：下载后**切勿解压**，直接保留 `.zip` 格式文件。

### 第二步：导入播放器
1. 打开手机中的 **Lyrico APP**；
2. 依次进入 **设置** → **搜索设置** → **插件管理**；
3. 点击右上角 **「+」号**，选择 **本地导入**；
4. 选中已下载的 `.zip` 文件即可完成安装。

### 第三步：偏好设置（可选）
- 在插件管理列表中点击进入插件配置项；
- **联系邮箱（可选）**：若希望在主引擎缺失时自动连接第三方开源备用库，可在此填入联系邮箱；若仅使用主引擎，留空即可；
- 建议在 Lyrico 设置中启用逐字流光动效，体验字级对齐的滚动效果。

## 常见问题

- **Q: 为什么部分曲目仅显示逐行滚动？**
  A: 插件优先匹配逐字时间轴。若检索源库中该曲目仅收录了标准单行时间轴或纯文本内容，将如实向播放器返回基础歌词。
- **Q: 联系邮箱是必填项吗？**
  A: 不是。主引擎完全独立运行，无需邮箱；仅在连接第三方备用源时作为合规标头使用。
