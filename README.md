# LrcRed Lyrics (Lyrico 专用逐字歌词插件)

这是一个专门为 [Lyrico](https://github.com/Replica0110/Lyrico)（Android 本地音乐元数据编辑器）定制的双引擎逐字歌词检索插件。

---

## 项目渊源与职责分工

- **母项目**：[Music-Tag-Lyrics](https://github.com/sxsxhhi/music-tag-lyrics)
  本插件的核心检索逻辑与版本仲裁算法，提取自桌面端音频元数据治理工具 `Music-Tag-Lyrics` 中最高优先级的主引擎模块。我们针对手机移动端的运行环境进行了轻量化改造，做成了即插即用的单文件 JavaScript 插件。
- **宿主项目**：[Lyrico APP](https://github.com/Replica0110/Lyrico)
  Lyrico 是一款功能强大、体验出色的 Android 本地音乐标签编辑与元数据管理工具（类似手机端的“音乐标签”）。
  
  **两者的分工非常清晰**：
  - **本插件**：专心当好“探路先锋”，负责根据本地音频的标题、艺人、时长等信息，在远端高精度检索，并返回原生的结构化逐字歌词数据（TTML 格式）；
  - **Lyrico 宿主**：拿到 TTML 逐字歌词后，由 Lyrico 根据您的全局设置自动转码（如转为带精准时间戳的增强型逐字歌词 ELRC、双语歌词或传统 LRC），最后直接写入音频文件的 ID3 标签，或保存为同名外挂歌词文件。

---

## 核心亮点

1. **双引擎自动切换，多重保障**
   - **主引擎**：优先检索高品质原生逐字歌词源，字级对齐，准确度极高；
   - **备用源**：若主引擎未命中，自动无缝切换到开源镜像库进行兜底补充。
2. **聪明识别版本，拒绝张冠李戴**
   - 搜歌词最忌讳把录音室原版匹配到了现场版（Live）或混音版（Remix），导致整首歌词时间轴全乱。插件内置了严格的版本互斥规则，智能阻断错配；同时对重制版（Remastered）、豪华版（Deluxe）等时间轴兼容的版本聪明放行。
3. **内置 12 小时本地查询缓存**
   - 无论是重复调试单曲，还是批量整理歌单，插件自带 12 小时本地查询缓存，再次检索秒级命中，既快又稳，还不怕频繁请求触发服务限流。
4. **开箱即用，免配置**
   - 默认状态下无需填写任何 Key 或邮箱，主引擎即可正常检索；若希望在主引擎缺词时启用备用开源库，也可随时在设置里填入联系邮箱。

## 保姆级安装与使用指引

### 第一步：获取插件包
前往本仓库的 [Releases 页面](https://github.com/sxsxhhi/LrcRed-Lyrics-Lyrico/releases) 下载最新版本的插件压缩包（文件名形如 `LrcRed-Lyrics-x.x.x-Lyrico-Plugin.zip`）。
> **注意**：下载完成后**千万不要解压**，直接保留 `.zip` 格式！

### 第二步：导入到 Lyrico
1. 打开手机上的 **Lyrico** 应用；
2. 进入 **设置** → **搜索设置** → **插件管理**；
3. 点击页面右上角的 **「+」号**，选择 **本地导入**；
4. 在文件选择器中选中刚才下载的 `.zip` 压缩包，即可完成安装。

### 第三步：设置歌词保存格式（推荐 ELRC）
1. 在 Lyrico 中进入 **设置** → **歌词** → **歌词模式**；
2. 建议勾选或选择 **增强型逐字歌词 (ELRC)**；
   - 这样 Lyrico 在保存歌词时，就会将本插件获取到的 TTML 数据完美转为带有 `<mm:ss.xxx>` 词级时间轴的逐字歌词，让支持逐字动效的播放器能够展现流畅的流光效果。

### 第四步：为歌曲刮削与保存歌词
1. 在 Lyrico 的歌曲列表或单曲详情页中，点击 **「搜索歌词」**；
2. 勾选或选择 **LrcRed Lyrics** 进行检索；
3. 检索出候选歌词后，点击即可查看预览；
4. 确认歌词与时间轴准确后，点击 **应用**，最后点击右上角的保存（**✓**），即可将逐字歌词正式写入本地音频文件标签或生成歌词文件。

## 常见问题

- **Q: 为什么搜出来的某些歌曲只有逐行滚动，没有逐字？**
  A: 插件会尽全力寻找逐字歌词源。如果远端源库中该歌曲本身只收录了普通单行时间轴（甚至纯文本），插件会如实返回基础歌词供您保存。
- **Q: 插件设置里的联系邮箱一定要填吗？**
  A: 不需要。主引擎完全独立运行，不填邮箱也能正常使用；联系邮箱仅在需要连接第三方开源备用库兜底时作为合规标头使用。
